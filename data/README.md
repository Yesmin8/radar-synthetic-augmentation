# Dataset

The original radar dataset is not stored in this repository.

This project uses:

Alexander Karlsson, “Radar Measurements on Drones, Birds and Humans
with a 77 GHz FMCW Sensor,” Version 2.0, Zenodo, 2021.

DOI: https://doi.org/10.5281/zenodo.5845259

The dataset is distributed under the Creative Commons Attribution 4.0
International licence.

After downloading the dataset, place the file at:

data/raw/data_SAAB_SIRS_77GHz_FMCW.npy

The preprocessing notebooks generate the required processed tensors.
